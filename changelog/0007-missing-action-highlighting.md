# 0007 — Подсветка пропущенных действий и фильтр по зонам ответственности

**Дата:** 2026-08-03

## Что изменилось
Для каждой зоны ответственности (продление до просрочки / 0-7 / 8-14 претензии / 15-28 изъятие / 29+ взыскание) задан список ожидаемых действий. Если по контрагенту ни разу не зафиксировано ни одно из них — строка подсвечивается, а в столбце «Рекомендуемое действие» появляется бейдж «Действие не зафиксировано». Проверка идёт по всей истории действий клиента, а не только по последнему — более поздний неважный комментарий не должен маскировать факт того, что нужное действие уже сделали.

Добавлен фильтр «только без нужного действия» в основную таблицу и отдельно в таблицу продления.

## Зачем
Нужно было явно видеть, по каким контрагентам ещё не произведено ожидаемое для их стадии действие, и иметь возможность отфильтровать именно таких — по каждой зоне ответственности отдельно.
