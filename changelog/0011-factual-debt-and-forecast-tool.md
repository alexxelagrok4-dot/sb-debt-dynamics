# 0011 — Факт. долг вместо «Задолженности», прогноз на дату

**Дата:** 2026-08-05

## Проблема

У контрагентов с давно остановленным начислением (например, списанных для налогового учёта) сырая колонка «Задолженность» из 1С может быть обнулена или заморожена, хотя реальный долг за пользование оборудованием продолжает копиться. Классификация по стадиям (0-7/8-14/…/29+) в денежном режиме считалась именно от этой колонки — такие контрагенты попадали в младшие стадии просрочки вместо 29+.

## Переосмысление колонок 1С

- **«Задолженность»** — это не факт за уже потреблённые дни аренды, а ожидаемый долг за **будущий** период по условиям предоплаты (оплата вносится за 5 дней до начала нового периода). Из расчёта стадии и факт. долга эта колонка исключена, показывается только справочно в карточке контрагента («Ожидаемый долг за след. период (по 1С, справочно)»).
- **«Прогноз задолженности»** — вопреки названию, это факт: реальный долг за уже потреблённые дни, пересчитываемый 1С заново на дату каждого отчёта из остатка аванса и суточного платежа. Теперь это основа для факт. долга и классификации по стадиям.

## Что изменилось

- Факт. долг = `max(0, Прогноз_задолженности − Аванс)`. Стадия считается из чистой позиции в днях `(Аванс − Прогноз_задолженности) / Суточный_платёж` — единая формула для «сейчас» и (см. ниже) для прогноза на будущую дату.
- База накопителя долга (`clientLedgers`), состав таблиц 0-7…29+, KPI и панель «Изменения за период» пересчитаны на эту формулу.
- Новый самостоятельный инструмент **«Прогноз задолженности на дату»**: дата-пикер (по умолчанию — конец текущего месяца) и таблица по всем контрагентам с тоннажем/долгом — факт. долг сейчас, прогноз на выбранную дату, прирост. Не влияет на стадии, KPI и панель «Изменения за период» — те всегда показывают факт на дату своих отчётов, без проекции вперёд.

## Зачем

Долг не должен «прятаться» из-за особенностей бухгалтерского учёта в 1С — с ним нужно работать независимо от того, продолжает ли 1С начислять аренду формально.
