# 0004 — Ручной выбор периода сравнения

**Дата:** 2026-08-03

## Что изменилось
Добавлен второй селектор «Сравнить с периодом» рядом с выбором отображаемой даты. По умолчанию он предлагает предыдущую по хронологии загрузку (как и раньше), но теперь можно вручную выбрать любую другую ранее загруженную дату в качестве базы для сравнения динамики.

## Зачем
При появлении новой загрузки (например, 10.08) нужна возможность сопоставить её не обязательно с ближайшей предыдущей неделей (03.08), а с любой другой уже загруженной датой (например, 27.07) — раньше сравнение всегда было жёстко привязано к хронологически ближайшей загрузке.
