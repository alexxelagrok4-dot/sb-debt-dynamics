СБ — динамика просрочки

Раз в неделю загружайте файл «отчёт СБ» из 1С — инструмент сам классифицирует стадию по каждому контрагенту (0–7 / 8–14 / 15–21 / 22–28 / 29+ дней) и сравнивает с прошлой загрузкой: кто ухудшился, кто оплатил, кто новый. Ниже — журнал произведённых действий по каждому контрагенту.

Автоматические замечания по загрузке несостыковки между этой и прошлой загрузкой — не ошибки сами по себе, но стоит проверить

Продление — заканчивается оплаченный срок аренды «Дней просрочки»=0 в отчёте — день окончания уже оплаченного срока; оплата за следующий период вносится за 5 дней до этой даты — то есть уже сейчас. Действие нужно ДО того, как клиент технически уйдёт в просрочку (с 0-го дня по отчёту 1С).

Задачи по отделам на этот период считается из текущих данных — не отдельный ручной план

Эффективность по стадиям что случилось с теми, кто был в стадии на прошлой загрузке — конверсия в деньги/тонны

Контрагенты в просрочке стадия считается от накопленного долга (после того, как исчерпан аванс), в днях суточного платежа — а не от календарных дней 1С; по умолчанию — сначала ухудшившиеся

Погашено / выбыло из просрочки за период частично или полностью — включая тех, кто ещё остался в отчёте
